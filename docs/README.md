# NeuroAlign Documentation

Welcome to the official documentation directory for the NeuroAlign pipeline. This folder contains detailed technical guides, architectural breakdowns, and developer resources that expand upon the quickstart instructions found in the main repository.

## Directory Index

* **Architecture Overview (ARCHITECTURE.md):** A detailed breakdown of the zero-copy memory mapping systems and the mathematical logic behind the temporal alignment engine.
* **Contributing Guide (CONTRIBUTING.md):** Step-by-step instructions on setting up a local development environment, running the automated test suite, and submitting pull requests.
* **API Reference:** Technical specifications and method definitions for the core Python classes, including the loaders, the filter engine, and the synchronizer.

## Future Plans

As NeuroAlign scales within the Experanto ecosystem, this documentation will eventually be converted into an automated site using tools like Sphinx or MkDocs. For now, all deep technical explanations are maintained here in standard markdown format.

If you are looking for basic installation instructions or command line interface examples, please refer to the primary README in the root of the repository.
